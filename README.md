# LSTM Stock Price Prediction

A deep learning project using historical stock market data and stacked Long Short-Term Memory (LSTM) networks.

## Technologies
Python, TensorFlow, Keras, Pandas, NumPy, Scikit-learn, Yahoo Finance, Google Colab, and Power BI.

## Goals
- Predict stock closing prices using historical data
- Apply proper preprocessing and scaling
- Train and evaluate stacked LSTM models
- Compare predictions against a naive baseline
- Visualize results using Power BI
